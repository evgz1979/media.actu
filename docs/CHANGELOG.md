# Журнал документации

## Поиск NAS — 2026-10-28

- добавлен поиск серверов SMB через Bonjour на M4 и чтение списка ресурсов;
- ресурсы можно запомнить без подключения и назначить им роли;
- команда подключения отдельно открывает Finder на M4;
- сохранённые списки и роли не теряются при ошибке доступа или смене имени Bonjour;
- оригиналы остаются только для чтения; пароли приложение не запрашивает;
- добавлены проверки обнаружения, ошибок доступа и привязки к существующим томам.

## Хранилища — 2026-10-28

- добавлен стартовый экран томов, дерева файлов и ролей;
- сохранён прежний медиаинтерфейс на `/media`, включая системную медиатеку;
- тома, снимки просмотренных папок и наследуемые роли хранятся в отдельной базе;
- оригиналы остаются только для чтения;
- порт Core 18765 теперь задан по умолчанию в Core и UI;
- добавлены проверки отключения, смены диска и сохранности исходных файлов.

## 0.1.0-dev — 2026-10-28

- рабочий Core media.actu закреплён за портом 18765; 8765 оставлен проекту «Зигзаг · Заказы»;
- описаны рабочий запуск на M4, разработка на ноутбуке и доступ через SSH-туннель;
- добавлены схема развёртывания и ADR-0003; сохранены требования режима чтения оригиналов.

## 0.1.0-dev — 2026-08-09

- создан каталог версионируемой документации;
- зафиксирована двухпроцессная архитектура Core + NiceGUI;
- описана граница режима только чтения;
- создан roadmap контролируемых операций, дедупликации, AI-анализа и работы с NAS/входящими носителями;
- описаны требования к журналу операций и откату.
- добавлен предустановленный источник системной медиатеки Photos;
- зафиксирован адаптер PhotoKit с официальным scripting fallback;
- двойной клик по объекту медиатеки открывает его в Photos без экспорта.
- описана отдельная стадия экспорта с профилями для личных, рабочих и других наборов;
- зафиксированы будущая обработка скриншотов и запрет автоматического удаления после экспорта;
- в интерфейс добавлена информационная секция «Экспорт» без файловых операций.
