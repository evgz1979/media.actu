# План реализации

## 0.1 — локальный каталог, только чтение

- [x] отдельные Core и UI процессы;
- [x] выбор нескольких источников;
- [x] разделение источников и хранилищ копий;
- [x] названия и комментарии для расположений;
- [x] исключение служебных AppleDouble-файлов;
- [x] предустановленный источник системной медиатеки через системный адаптер Photos;
- [x] чтение метаданных и превью Photos без доступа к `.photoslibrary`;
- [x] рекурсивный обход вложенных папок;
- [x] SQLite-каталог;
- [x] наблюдение за изменениями;
- [x] дерево папок;
- [x] две независимые панели деревьев и сверка выбранных папок на главной;
- [x] фото-превью в отдельном кэше;
- [ ] видео-превью через FFmpeg;
- [ ] извлечение EXIF и видеометаданных;
- [ ] поиск, фильтры и пагинация;
- [ ] корректная обработка отключения и повторного подключения носителя;
- [ ] ленивая загрузка больших деревьев.

## 0.2 — входящие носители и размещение копий

Новые операции добавляются в общую главную с двумя панелями, без отдельных
страниц для каждой операции. На текущем этапе доступны просмотр и сверка;
копирование, перемещение и удаление требуют отдельной реализации.

- обнаружение подключённых флешек и SSD;
- профиль входящего носителя;
- план импорта без автоматического изменения источника;
- [x] SHA-256 для кандидатов одинакового размера;
- [x] read-only сверка содержимого на выбранных томах NAS;
- [x] сохраняемые задачи сверки, остановка/продолжение и журнал;
- отчёт об отсутствующих и повреждённых экземплярах.

## Будущая задача — поиск ненужных файлов

- [ ] воспроизвести подход к поиску ненужных файлов из прежнего чата на ноутбуке;
- [ ] перед реализацией восстановить из того обсуждения критерии и исключения;
- [ ] показывать кандидатов и причины для ручного решения пользователя;
- [ ] хранить результаты поиска в каталоге приложения; удаление не выполнять автоматически.

## 0.3 — дубликаты

- точные дубликаты по криптографическому хэшу;
- визуально похожие фото по perceptual hash;
- группировка Live Photo и связанных sidecar-файлов;
- решение пользователя о главном экземпляре;
- удаление только через план, карантин и обратимый журнал.

## 0.4 — управляемая перестройка папок

- правила структуры по дате, событию и устройству;
- симуляция нового дерева;
- обнаружение конфликтов имён;
- транзакционный план копирования/перемещения;
- проверка хэшей до удаления старого размещения;
- откат структуры.

## 0.5 — AI-анализ содержимого

- локальные или явно выбранные облачные модели;
- описание сцены, объектов и качества кадра;
- лица только при отдельном включении;
- географические и событийные группы;
- хранение модели, версии промпта и уверенности результата;
- возможность полностью удалить производные AI-данные.

## 0.6 — экспортные профили

- отдельные назначения для личных, рабочих, сайтовых и пользовательских наборов;
- правила отбора и исключения файлов для каждого профиля;
- предварительный расчёт состава экспорта без записи;
- уменьшение, конвертация и другие производные преобразования;
- извлечение полезного текста из скриншотов;
- проверка результата до изменения политики хранения оригинала;
- удаление ненужных скриншотов и экземпляров только отдельным подтверждаемым планом;
- журнал результатов, карантин и откат файловых операций.

## 1.0 — эксплуатационная версия

- политика количества экземпляров;
- снимки состояния каталога;
- аудит всех операций;
- восстановление после сбоя;
- проверенный сценарий отката;
- резервное копирование базы и журнала;
- документация аварийного восстановления.
