# Проверка документации — 2026-11-03

Это исторический протокол первоначального описания. Текущие справочники используют
устойчивые якоря и проверяются сравнением смыслового результата генерации.
Порядок обновления и проверки изложен в [руководстве](development/documentation.md).

Версия продукта и документации: `0.1.0-dev`. Исходная ревизия перед работой:
`7bf1edb` (`Persist sidebar expansion preferences`). Рабочее дерево перед началом
было чистым. Запуск и развёртывание на M4 не выполнялись.

## Объём и покрытие

- Сверены и актуализированы прежние руководства и все восемь ADR.
- Справочник охватывает 37 производственных Python-модулей, 71 класс и 733
  определения функций/методов, включая вложенные именованные обработчики.
- Все 804 определения имеют две строки пояснения перед объявлением/декораторами
  и отдельную запись справочника с точной ссылкой на исходник.
- Дополнительно описаны и прокомментированы функции двух Objective-C-исходников,
  методы Vue-компонента, действующий AppleScript и старые JXA/AppleScript-сценарии.
- HTTP-справочник содержит 84 маршрута Core, 26 схем запросов и две схемы
  ошибок валидации FastAPI/Pydantic.
- Схема данных содержит все 49 таблиц: 17 в catalog.sqlite3 и 32 в storage.sqlite3,
  итоговые столбцы, индексы, внешние ключи, CHECK и UNIQUE.
- Добавлен индекс существующих сценариев 36 тестовых модулей.
- Итоговый набор — 68 Markdown-документов, включая корневой README; проверены
  4182 локальные и внешние ссылки, из них 2753 ведут к исходным файлам. Битых
  локальных путей, строк #L и внутренних якорей не найдено.
- Старые функции, скрипты, поля, таблицы и CSS не удалялись; статусы описаны
  в [реестре](legacy.md).

## Сохранение поведения

Python сравнивался с сохранённым исходным состоянием двумя способами:
`ast.dump(..., include_attributes=False)` и последовательностью токенов без
COMMENT/NL. Во всех 37 модулях результаты равны исходным. Существующие docstring,
сигнатуры, декораторы, выражения и строковые литералы сохранены.

В JavaScript, Objective-C и AppleScript сравнивались исполняемые лексические
токены с сохранением содержимого строк после исключения комментариев и внешних
пробелов. Все шесть файлов совпали с исходными. В Vue watch-обработчики дополнительно
разнесены для двухстрочных пояснений; их выражения сохранены.

Это подтверждает отсутствие изменения логики данным набором правок. Известные
ограничения прежней реализации описаны отдельно, а не исправлялись скрыто вместе
с документацией.

## Тесты

Итоговая команда из корня проекта:

```sh
.venv/bin/python -m unittest discover -s tests -v
```

**Результат: 380 тестов, OK, 19,365 секунды.** Итоговый прогон выполнялся с доступом
к локальным Unix-сокетам и нативному декодеру macOS.

Первый запуск в sandbox завершился двумя ошибками и четырьмя пропусками:
fake-helper не мог подключить локальный Unix-сокет, AVFoundation не получил кадр
видеофикстуры. Обе ошибки отдельно повторно проверены вне sandbox — 2 теста, OK.
После этого полный итоговый прогон прошёл без ошибок и пропусков. Тесты ради
прохождения не менялись.

## Синтаксис и ссылки

- `clang -fsyntax-only -fobjc-arc -fblocks photos_adapter/main.m` — успешно.
  SDK выдал пять предупреждений об использовании PHAssetResource.originalFilename,
  deprecated начиная с macOS 27; реализация сохранена.
- `clang -fsyntax-only -fobjc-arc -Wno-deprecated-declarations media_manager/video_frame.m`
  — успешно.
- Node `--input-type=module --check` для paired_tree.js и `--check` для scan.js
  — успешно, скрипты не выполнялись. Использован комплектный Node среды Codex,
  поскольку в shell PATH отдельный node отсутствовал.
- Проверены все локальные Markdown-ссылки, существование целевых файлов,
  допустимость строк #L и внутренние якоря оглавлений.
- Проверены соответствие справочника всем определениям, отсутствие нераскрытых
  шаблонов ссылок, согласованность VERSION/docs/VERSION и `git diff --check`.

## Границы проверки

Схема и OpenAPI получены на новых временных базах с отдельным MEDIA_ACTU_DATA_DIR.
Импорт app инициализировал таблицы, lifespan не запускался: рабочие носители,
наблюдатели, очередь и реальная медиатека Photos для этого не использовались.

Не проверялись текущее состояние M4, его Launcher/sandbox-профиль, туннель,
выданные системные разрешения, Apple ID, содержимое пользовательских носителей
или фактическое число независимых исправных копий. Статические списки вызовов
в справочнике не заменяют runtime-трассировку, а кандидаты без найденных вызовов
не объявлены безопасными для удаления без отдельной проверки внешних клиентов.

## Устойчивость генерации — 2026-11-05

В репозитории появился воспроизводимый генератор со смысловыми метаданными.
Его `--check` пересобирает ожидаемые страницы, проверяет покрытие пояснений,
локальные пути и якоря и сравнивает результат с файлами. Текущие правила
навигации описаны в [руководстве поддержки](development/documentation.md).

Изолированная копия дерева подтвердила следующие результаты.

- После вставки пустых строк и обычных комментариев в app.py, ui.py, Catalog,
  генератор, тестовый модуль, Vue-компонент и PhotoKit-helper все 43 генерируемые
  страницы остались побайтно одинаковыми. Проверка актуальности дала нулевой diff.
- Изменение только значения по умолчанию параметра `format_bytes` изменило только
  его сигнатуру в `docs/reference/ui.md`. Остальные страницы совпали побайтно.
- Все локальные ссылки после сдвига строк остались действительными.
- 13 новых тестов проверили удаление функций и модулей, потерю пояснений,
  осиротевшие страницы, отсутствующие якоря, повторные имена, getter/setter,
  watch/methods Vue и сохранение значимого релизного хеша.
- Полный прогон выполнил 393 теста за 18,175 секунды и завершился OK.

Пояснения исходников получили метки `#:`, `//:` и `--:`. Сравнение AST и
исполняемых токенов с состоянием перед миграцией подтвердило сохранение
производственной логики и строковых литералов. Алгоритмы и значения хеширования
данных, кэша и файлов сохранены. Схемы API и SQLite снимались на временных данных.
