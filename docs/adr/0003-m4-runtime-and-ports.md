# ADR-0003: рабочая машина M4 и отдельный порт Core

Статус: принято

Дата: 2026-10-28

Применимо к версии: `0.1.0-dev`

## Решение

Рабочий media.actu выполняется на Mac mini M4. Ноутбук используется для разработки
и развёртывания изменений. Core слушает `127.0.0.1:18765`, UI — `127.0.0.1:8090`.
С ноутбука UI открывается через SSH-туннель на `127.0.0.1:18090`; Core и превью
туннелируются на `127.0.0.1:18765`.

## Причины

На M4 находятся прежний каталог, кэш и системная медиатека Photos. Порт 8765
занят проектом «Зигзаг · Заказы». Остановка чужого процесса ради media.actu недопустима.

## Последствия

Рабочие порты задаются локальной конфигурацией запуска. Старые жёстко заданные
адреса в исходниках пока не меняются. База и кэш M4 сохраняются независимо от
развёртывания кода. Решение уточняет порт и размещение из ADR-0001, сохраняя
двухпроцессную архитектуру.
