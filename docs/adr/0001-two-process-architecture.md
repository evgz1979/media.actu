# ADR-0001: два независимых процесса

Статус: принято
Дата: 2026-08-09

## Решение

Использовать FastAPI Core на `127.0.0.1:8765` и NiceGUI UI на `127.0.0.1:8090`.

## Причины

- Core должен продолжать индексирование при закрытом браузере.
- UI не должен иметь прямого доступа к оригиналам и базе.
- Python используется для обоих процессов без Node/TypeScript toolchain.
- UI можно заменить, сохранив Core API и каталог.

## Последствия

- требуется запуск двух сервисов;
- UI должен корректно показывать недоступность Core;
- между процессами существует версируемый HTTP-контракт;
- в будущем Core можно оформить как `launchd`-службу.
