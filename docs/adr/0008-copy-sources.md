# ADR-0008: источники копирования и цепочки копий

Статус: принято
Дата: 2026-11-02

## Обычные папки

Каждая копия может получать файлы из основной папки `00-main` либо из другой
копии того же набора. По умолчанию сохраняется прежний источник `00-main`.
Выбор хранится по постоянным ID папок в `copy_sources`, поэтому смена номера
или типа копии не меняет маршрут. Циклы и источники из другого набора запрещены.
Отключённый либо удалённый источник блокирует действие, автоматического перехода
на основную папку нет.

Сверка открывает выбранный источник слева и назначение справа. План копирования
содержит оба постоянных ID и пути; перед записью маршрут проверяется снова.
Смена источника делает прежнюю сверку и план непригодными для продолжения.
Копируются только отсутствующие файлы, существующие не заменяются.
В меню копии доступен «Источник копирования…», выбранная связь видна в списке,
дереве и свойствах папки.

## Копии Photos

Аналогичная связь хранится в `photos_copy_sources`. Источником может быть Photos
либо другая привязанная копия этой же медиатеки. Нумерация и маршруты независимы:
команда «Сделать 01-copy» меняет только номера, сохраняя ID, файлы и квитанции.
Структурных `00-main` для медиатеки не создаётся.

Рабочая схема M4: `Photos → 01-copy NVMe Apple/evgz → 02-copy HDD Apple/evgz`.
NVMe — постоянная полноценная копия. Отдельного временного буфера оригиналов на
системном диске или в кэше приложения нет.

Перед загрузкой недостающих оригиналов первая копия восстанавливается из уже
сохранённых ресурсов других копий. Используются постоянный ID объекта/ресурса,
версия Photos, размер и параметры исходного файла. Известные ресурсы идут первыми,
в порядке папок и дат. Они читаются один раз для фактической передачи на NVMe.
Если известный сохранённый файл или его том недоступен либо параметры изменились,
восстановление ожидает исправления; повторного скачивания из Photos вместо него нет.
Существующие записи HDD, имена, пути и данные сохраняются.

После подготовки текущего манифеста и через каждые 256 обработанных ресурсов,
а также в конце прохода, готовые файлы передаются в зависимые копии. Порядок
топологический, внутри назначения — по пути. Учитываются только завершённые
ресурсы выбранного источника с подходящей версией. Недостающие в источнике
ожидаются; прямого скачивания Photos для зависимой копии нет. Отключённая вторая
копия не мешает пополнять первую; при её подключении догоняются только пропуски.

Один фоновый worker управляет всей цепочкой, у каждой копии свой прогресс,
манифест, корень и журнал. Пауза/продолжение любой копии управляют корнем цепочки.
Действует существующее ночное окно; цепочка работает для активной системной
медиатеки, смена аккаунта останавливает текущую передачу. Инвентаризация метаданных каждого назначения
выполняется один раз за проход, а не перед каждой партией.

Передача между копиями использует ограниченный буфер 64 МиБ и создание нового
конечного файла из ADR-0007. Источник проверяется по метаданным и привязке до,
во время и после передачи; результат не перечитывается ради проверки. Контрольные
суммы не вычисляются. Завершённые ресурсы и незавершённые пути переживают перезапуск.
Незавершённые конечные файлы не перезаписываются, новый результат получает свободное имя.
