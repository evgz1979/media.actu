# ADR-0002: первая версия работает только на чтение

Статус: принято
Дата: 2026-08-09

## Решение

До реализации журнала, планов, проверки копий и отката Core API не содержит операций изменения оригиналов.

## Разрешено

- обход папок;
- чтение метаданных;
- чтение фото для производного превью;
- обновление собственной SQLite-базы и кэша.

## Запрещено

- менять имена и содержимое оригиналов;
- перемещать оригиналы;
- удалять оригиналы;
- автоматически исправлять структуру источников.

## Переход к режиму записи

Режим записи потребует отдельного ADR с моделью планирования, журналом, карантином, политикой копий и испытанным сценарием отката.
