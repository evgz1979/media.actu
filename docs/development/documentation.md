# Как поддерживать справочники

Подробные справочники строит `scripts/build_documentation.py`. Постоянные смысловые
описания модулей, таблиц и тестовых областей находятся в
`scripts/documentation_metadata.json`. Полные сигнатуры, поля, вызовы, исключения,
ветви возврата и связи модулей вычисляются из текущих исходников.

## Обычное обновление

Из корня проекта выполни генерацию и затем проверку.

```sh
.venv/bin/python scripts/build_documentation.py
.venv/bin/python scripts/build_documentation.py --check
```

Генерация записывает только изменившиеся страницы. `--check` строит тот же ожидаемый
набор в памяти, проверяет ссылки, сравнивает результат с файлами и возвращает код 1
при расхождении. Ошибка показывает diff затронутых описаний. Новый или удалённый
модуль требует согласования реестра в метаданных. Страница, оставшаяся без модуля,
также обнаруживается.

Команды включены в правила перед коммитом. Изменённое поведение дополнительно
описывается в руководстве соответствующего сценария, архитектуре или ADR.

## Что генерируется

| Документы | Источник |
| --- | --- |
| `docs/reference/*.md` для Python | AST, помеченные пояснения, импорты и метаданные модуля |
| `docs/reference/tests.md` | Именованные test-методы и их области видимости |
| `docs/reference/native.md` | C-функции, Objective-C-классы/селекторы, методы Vue и точки входа скриптов |
| `docs/reference/README.md` | Реестр модулей и покрытие объявлений |
| `docs/api.md` | Фактический OpenAPI и пояснения обработчиков |
| `docs/data-model.md` | Пустые SQLite-схемы после действующих миграций и описания таблиц |

Руководства сценариев, языковые разборы, ADR, журнал и исторические протоколы
редактируются содержательно. Ссылки в них проверяются тем же генератором.

## Устойчивая навигация

Внутри страницы Python-модуля определение имеет якорь вида
`symbol-Catalog.connect`. Полное лексическое имя включает содержащие классы и
функции, например `PhotosOriginals._save.flush`. Регистр и подчёркивания сохраняются.
Одинаковые короткие имена в разных областях получают разные якоря.

При повторном объявлении одного полного имени первая запись сохраняет базовый
якорь, следующая получает `--declaration-2`, затем `--declaration-3`. Это охватывает
в том числе getter и setter свойства. Суффикс зависит от порядка объявлений одного
имени, поэтому пустые строки и комментарии на него не влияют.

Константы имеют `constant-ИМЯ`. Тестовые методы включают имя тестового модуля.
Нативные определения включают имя исходного файла, область Vue или Objective-C-класс
и селектор. Двоеточия селектора кодируются при построении URL.

Ссылка на функцию ведёт к её записи с устойчивым якорем. В записи показаны полное
имя и сигнатура, рядом находится ссылка на исходный модуль. Это сохраняет навигацию
при вставках строк выше определения. Ссылки вида `file.py#L123` проверка отклоняет.

## Две строки пояснения

Для определения Python используются две помеченные строки перед объявлением или
его декораторами.

```python
#: Масштабирует переданное значение.
#: Использует явно переданный коэффициент.
def scale(value: int, factor: int = 1) -> int:
    return value * factor
```

Обычные комментарии и пустые строки могут стоять рядом с этим блоком. Генератор
выбирает только `#:` и требует ровно две непустые строки. Изменение помеченного
пояснения отражается в описании. Потеря одной строки, даже при наличии обычных
комментариев, останавливает проверку покрытия.

Нативный аналог использует `//:` в JavaScript/Objective-C и `--:` в AppleScript.
Анонимные lambda, arrow-callback и Objective-C blocks описываются у именованного
владельца. Именованные вложенные функции получают собственные записи.

## Изоляция API и схемы

Основной разбор Python выполняется через AST. Для OpenAPI и окончательной схемы
SQLite генератор создаёт дочерний процесс и отдельный временный `MEDIA_ACTU_DATA_DIR`.
Дочерний процесс инициализирует Core с отключённой поддержкой PhotoKit, считывает
структуру пустых баз и OpenAPI и завершает работу. Снимок содержит контракты и DDL.
Сервер и lifespan при этом не запускаются. Используется интерпретатор `.venv`,
в котором установлены зависимости проекта.

Временные данные удаляются после чтения. В Git сохраняются имена, сигнатуры,
ограничения, структура таблиц и пояснения. Время генерации, позиции AST и хеши
целых исходников для документационной актуальности в результат не входят.
Хеши, используемые приложением для релизов, файлов, кэша и проверки содержимого,
продолжают описываться как обычная часть контракта.

## Проверки устойчивости

```sh
PYTHONPATH=tests .venv/bin/python -m unittest -v test_documentation
```

Изолированные примеры проверяют равенство всего построенного набора после сдвига
строк и вставки обычных комментариев. Изменение значения параметра по умолчанию
меняет только сигнатуру соответствующего определения в его странице.

Дополнительно проверяются одноимённые объявления, регистр имён, getter/setter,
различение watch и methods в Vue, исчезновение функции или модуля, потеря пояснения,
устаревшие и осиротевшие страницы, отсутствующие файлы и якоря. Значимый релизный
хеш в константе сохраняется в справочнике. Для изолированного дерева командная
строка также поддерживает `--root ПУТЬ`.

Первоначальная миграция заменяет построчные ссылки и расположение разделов.
Дальнейший diff отражает изменения смысловых записей и связанных контрактов.
