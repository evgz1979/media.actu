# NiceGUI, состояние вкладки и Vue

## Процесс UI и клиент Core

[`core_request`](../reference/ui.md#symbol-core_request) лениво создаёт один `httpx.AsyncClient` на процесс UI:
base_url=CORE_URL, до 30 соединений, 10 keep-alive, срок keep-alive 60 секунд.
Каждая операция передаёт свой timeout; после ответа вызывается raise_for_status,
затем response.json. При остановке UI пул закрывается через on_shutdown.
Это серверный HTTP-клиент; браузер отдельно получает JPEG по URL Core.

[`register_workspace_page`](../reference/workspace_ui.md#symbol-register_workspace_page) задаёт reconnect_timeout=120.
Краткий обрыв WebSocket не равен перезапуску UI: клиент может восстановиться,
а периодические запросы проверяют has_socket_connection/is_deleted.
[`StorageWorkspace.poll_connected`](../reference/workspace_ui.md#symbol-StorageWorkspace.poll_connected) не запускает обработку для
уже удалённого клиента. Полный перезапуск процесса требует новой страницы.

## Объекты интерфейса

`StorageWorkspace` владеет списком томов, активной панелью, отчётами, размерами,
состоянием редактирования и компонентами `CopyGroupsUI`, `PhotoLibrariesUI`,
`PairedWorkspace`. `BrowserPane` владеет выбором одного тома, корнем, папками,
раскрытием, режимом tree/preview и `StoragePreview`. У правой панели есть
`ComparisonTree` для найденных путей общей сверки.

Элементы NiceGUI строятся в `with ui.row()/column()/card()`: контекст определяет
родителя новых элементов. `with self.ws.client` восстанавливает контекст конкретной
страницы в асинхронном обработчике. Без него поздний callback мог бы попытаться
изменить элементы вне нужного клиента. Карта методов — [workspace_ui](../reference/workspace_ui.md).

## Обычное дерево и поколения запросов

[`BrowserPane.show_volume`](../reference/workspace_ui.md#symbol-BrowserPane.show_volume) увеличивает generation, сбрасывает
контекст прежнего тома и сначала получает сохранённый список. Если том доступен,
запускает фоновое обновление. В `load_folder` ответ принимается только если
generation всё ещё совпадает. Быстрый переход к другой папке не должен позволить
старому медленному SMB-ответу заменить новое представление.

У StoragePreview и PairedWorkspace собственные поколения. Смена режима или
открытие другого отчёта инвалидирует ожидаемые ответы соответствующего владельца.
Это защита состояния UI, а не отмена файловой операции Core.

`read_directory` выбирает обычный `/api/storage/volumes/.../directory` или
`/api/photos/libraries/.../browse`. Photos получает offset/limit; обычная папка
возвращает свой непосредственный список. Для отчётов используются отдельные API
tree/target-tree, которые читают сохранённый индекс.

## Выбор, путь и превью

Выбор в дереве меняет path/kind/entry и активную панель. Если соседняя панель в
preview, [`StorageWorkspace.preview_selection`](../reference/workspace_ui.md#symbol-StorageWorkspace.preview_selection) передаёт ей объект.
Превью не заменяет сохранённое состояние собственного дерева: при возвращении
tree восстанавливаются путь, раскрытие и прокрутка. Одновременно в режиме preview
может быть только одна сторона; включение другой возвращает прежнюю к дереву.

Кликабельный путь строится относительно допустимой границы. Для пары это выбранный
корень стороны, для Photos — виртуальная иерархия, для обычного тома — его корень.
`scope()` исключает Photos и неподтверждённые носители из обычных файловых операций.

[`StoragePreview.image_url`](../reference/storage_preview_ui.md#symbol-StoragePreview.image_url) выбирает готовое media-thumbnail
для Photos и storage-preview для обычного файла. Photos-плитки могут ожидать JPEG;
preview-status сообщает готовые media_id без повторной сборки всей сетки.
Папки открываются плитками, файлы — крупно, остальные типы получают информационное состояние.

## Связанные панели

[`PairedWorkspace.link`](../reference/paired_workspace_ui.md#symbol-PairedWorkspace.link) выбирает актуальный источник копии,
сохраняет независимые состояния панелей и связывает области. Открытие связи само
не запускает рекурсивную сверку. `unlink` останавливает активную работу, очищает
связанный вид и восстанавливает прежние деревья, не удаляя сохранённую связь.

`visible_rows` отбирает строки по общему корню, раскрытию, скрытым именам и фильтру
различий. Родительские папки различий остаются, чтобы путь был понятен. Файлы
непосредственно в текущем корне файлового отчёта имеют отдельное раскрытие.
Два компонента получают одинаковый порядок строк и общий выбранный относительный путь.

## Vue и виртуализация

`PairedTree` — NiceGUI Element с `component='paired_tree.js'`. Его `_props`
становятся Vue props, `self.on(...)` принимает события. `set_rows` обновляет rows/selected
и вызывает update. В JavaScript data содержит top/height/selection, computed вычисляет
start и visible, watch согласует серверное и локальное выделение.

Высота строки 28 px. `start=max(0,floor(top/28)-8)`, срез включает высоту viewport
и 16 строк запаса. Полная высота контейнера остаётся rows.length*28, но DOM-узлы
создаются лишь для visible. Это виртуализация отображения: сам набор строк уже
загружен в память; она не означает SQL-загрузку каждой строки по scroll.

События `select`, `open`, `toggle`, `context`, `toggle_files`, `menu_state`
переносят path/side/action к Python-обработчикам. Вертикальная прокрутка соседнего
viewport выравнивается при расхождении более пикселя. ResizeObserver обновляет
height и отключается в beforeUnmount. Все методы с кодом: [нативный справочник](native.md).

## Клавиатура, щелчки и меню

Стрелки перемещают только выделение по уже видимым строкам. Проверяются модификаторы,
IME, поля ввода и открытое меню, чтобы не перехватить штатный ввод формы.
Выбранная строка прокручивается в viewport, затем сервер получает keyboard=true.
Двойной щелчок по папке делает её корнем; раскрытие отдельной ветви не обязано
менять корень. Общие JS-обработчики обычного дерева находятся в workspace_ui,
а различение двойного клика папки — в FOLDER_CLICK_JS из storage_ui.

Контекстное меню помечает context_menu_open. Фоновый опрос не должен заменять
редактируемые элементы в этот момент. Для виртуального Photos скрываются файловые
команды Finder/свойств обычного тома. Callback из цикла фиксирует элемент аргументом
по умолчанию; подробнее о замыканиях — [языковые механизмы](language.md).

## Два вида сохраняемого состояния

| Состояние | Где | Срок и область |
| --- | --- | --- |
| Пути, выбранные тома, активная сторона, режимы, отчёт, раскрытие пары | sessionStorage браузера, media-actu.workspace.v1 | Конкретная вкладка |
| Раскрытие Тома/Медиатеки/Основные папки/архивов | app.storage.user, media-actu.sidebar.v1 | Предпочтение браузерного пользователя на UI-сервере |
| Списки файлов, сверки, копии, медиаданные | SQLite Core | Не являются браузерным снимком навигации |

[`StorageWorkspace.persist_workspace`](../reference/workspace_ui.md#symbol-StorageWorkspace.persist_workspace) сериализует компактный снимок
и не пишет его повторно при том же payload. `normalize_state` проверяет версию,
ID, относительные пути и две панели, ограничивает список раскрытых папок 2000.
Некорректный снимок отклоняется целиком. Списки файлов и содержимое не сохраняются
в sessionStorage. Раскрытие боковых секций читается до создания UI, чтобы не было
вспышки состояния по умолчанию; callback сливает изменение с последним app.storage.user,
сохраняя предпочтения, изменённые другой вкладкой.

## Обновления без потери фокуса

Поллинг сравнивает признаки состояния и обновляет только изменившиеся части:
подписи размеров, ёмкость, прогресс, готовые изображения. Полная перерисовка дерева
может уничтожить DOM-фокус и прокрутку, поэтому обновление томов отделено от
перестроения строк. В тестах это проверяется через подмены вызовов render, клиентских
callback и последовательность асинхронных ответов, а не реальным чтением NAS.

## Совместимость старых страниц

`/media?source=N` направляется на `/?source=photos-N`.
`/compare` переносит непустые source/path/job на `/` с HTTP 307.
Старый диалог «Прежние отчёты по именам» доступен из истории пары и содержит
действующие команды общей сверки. Эти маршруты и модуль ComparisonTree сохраняют
живые функции совместимости. Их нельзя объявлять неиспользуемыми только по имени.
