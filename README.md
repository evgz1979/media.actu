# media.actu

Минимальный локальный медиа-индексатор на Python.

## Гарантии первой версии

- работает только на `127.0.0.1`;
- сканирует выбранные папки рекурсивно;
- читает только имена, размеры и даты изменения медиафайлов;
- не переименовывает, не перемещает, не удаляет и не изменяет оригиналы;
- не переходит по символическим ссылкам;
- не отправляет пути и файлы в интернет.

## Запуск

```bash
source .venv/bin/activate
python app.py
```

После запуска открыть в Safari: <http://127.0.0.1:8765>
