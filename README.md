# media.actu

Локальный медиа-менеджер с отдельным Core-сервисом и браузерным интерфейсом.

Текущая версия: `0.1.0-dev`. На этом этапе приложение работает только на чтение.

## Сервисы

- Core API: <http://127.0.0.1:8765>
- NiceGUI: <http://127.0.0.1:8090>
- Core API docs: <http://127.0.0.1:8765/docs>

## Запуск

В первом терминале:

```bash
source .venv/bin/activate
python app.py
```

Во втором терминале:

```bash
source .venv/bin/activate
python ui.py
```

После запуска открыть в Safari: <http://127.0.0.1:8090>

## Безопасность версии 0.1

- выбранные источники и все вложенные папки сканируются рекурсивно;
- символические ссылки пропускаются;
- Core читает имена, размеры, даты и содержимое фото для создания превью;
- превью и SQLite-каталог хранятся только в `data/`;
- исходные папки не изменяются;
- UI не имеет прямого доступа к файловой системе и базе.
